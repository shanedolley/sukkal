Decide whether this candidate fact will still be true in a month.

A fact passes when it is durable: a decision taken, a contract term, a
preference someone stated, how a system works. It fails when it is a passing
state that a month will overwrite: a queue length, a mood, an in-flight status,
a number that moves weekly.

When you cannot tell, fail it. A candidate kept out can be raised again. A
transient one written down reads as current for years.

Answer on the first line with exactly `PASS` or `FAIL`, then a colon and one
short sentence giving the reason. Write nothing else. Do not hedge, and do not
explain your reasoning at length: an answer that is neither `PASS` nor `FAIL`
is read as an error and rejects the candidate.
